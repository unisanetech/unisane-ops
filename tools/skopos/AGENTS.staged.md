# Unisane Ops Agent Contract

This file is a staged declaration for the extracted standalone repository. While this
directory remains inside the umbrella repository, the root `AGENTS.md`, umbrella
Skopos, and the umbrella root lockfile are the sole workflow and install authorities.

Unisane Ops owns the `unisane-ops` package and binary, Ops engine, Cloud, Growth, Web
Runtime, provider families, the optional descriptor-only Framework Ops adapter, and
admitted presentation/host adapters. It does not own the Framework `unisane` CLI,
Framework product tooling, UI source, company desired state, provider state,
credentials, secrets, or an independent approval or workflow engine.

After extraction, admit this contract only through existing-project Skopos adoption.
Run the repository-local source-boundary check before package checks. Never publish,
deploy, mutate providers, or use credentials without separately admitted authority.
