# True Resume Growth Operations

Unisane Ops owns the provider and operations side of True Resume Growth. Load only the
procedure relevant to the operation:

- [Growth Provider Operations](../../guides/true-resume/growth-provider-operations.md)
- [Advertising Asset Provider Operations](../../guides/true-resume/ads-asset-provider-operations.md)
- [Research Provider Evidence](../../guides/true-resume/research-provider-evidence.md)

True Resume product intent, conversion semantics, reviewed creative facts, and curated
redacted research remain in the product-owned
[`standalone-products/true-resume/docs/domains/growth`](https://github.com/unisanetech/unisane-platforms/blob/main/standalone-products/true-resume/docs/domains/growth/README.md)
Memory family. Credentials, raw exports, private identifiers, mutable receipts, and
provider state are never promoted into either public Memory surface.

This public operations family contains mechanism and control documentation only. It
does not contain product evidence payloads, account or resource state, provider plans,
metrics, snapshots, fixtures, or mutable receipts.
